# História dos Craques - Seleção Brasileira

Uma experiência nostálgica interativa com efeito parallax apresentando os grandes craques da Seleção Brasileira.

## 🎮 Funcionalidades

### Funcionalidades Principais
- **Tela Inicial**: Vídeo de fundo com botão para iniciar a experiência
- **Efeito Parallax**: Scroll suave com imagens dos jogadores em movimento
- **Ordem Cronológica**: Jogadores apresentados em ordem crescente de época
- **Boxes Informativos**: Descrição detalhada de cada jogador e sua história na seleção
- **Controle de Música**: Botão para pausar/reproduzir e controle de volume
- **Design Moderno**: Interface responsiva e visualmente atraente
- **Animações Suaves**: Transições e efeitos visuais elegantes

### Funcionalidades Avançadas ✨
- **Sistema de Partículas Douradas**: Partículas animadas no fundo durante o scroll
- **Estatísticas Animadas**: Números animados mostrando gols, jogos e copas de cada jogador
- **Timeline Interativa**: Linha do tempo lateral mostrando todos os jogadores e permitindo navegação rápida
- **Modo Auto-Scroll**: Apresentação automática que navega pelos jogadores automaticamente
- **Efeitos Sonoros**: Som de torcida sintético ao passar por cada jogador
- **Navegação por Teclado**: Atalhos para controlar a experiência

## 🚀 Como Usar

1. Abra o arquivo `index.html` em um navegador moderno
2. A tela inicial será exibida com o vídeo de fundo
3. Clique em "Começar Experiência" para iniciar
4. Role a página para navegar pelos jogadores
5. Use o controle de música no canto superior direito para pausar/ajustar volume

## 🎨 Personalização

### Cores
As cores podem ser ajustadas no arquivo `styles.css` através das variáveis CSS:
- `--cor-primaria`: Dourado (#FFD700)
- `--cor-secundaria`: Verde (#009739)
- `--cor-terciaria`: Azul (#012169)

### Jogadores
Para adicionar ou modificar jogadores, edite o arquivo `index.html` seguindo a estrutura das seções existentes.

## 🎵 Música

A música "Copa de 82 - Voa Canarinho" toca automaticamente quando a experiência inicia. Alguns navegadores podem bloquear o autoplay - nesse caso, clique em qualquer lugar da página para ativar.

## ⌨️ Atalhos de Teclado

- `Espaço` ou `Enter`: Iniciar experiência (quando na tela inicial)
- `M`: Alternar música (pausar/reproduzir)
- `A`: Ativar/desativar modo auto-scroll
