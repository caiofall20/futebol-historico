## Onde encontrar as imagens?

1. **Wikimedia Commons**: https://commons.wikimedia.org
   - Busque por: "FC Barcelona 2009 team photo"
   - "Arsenal 2004 squad"
   - etc.

2. **Google Images**: Busque por "time histórico [nome do time] [ano]"

3. **Sites de notícias esportivas**: Arquivos históricos

## Formato recomendado

- Extensão: `.jpg` ou `.png`
- Resolução: Mínimo 800px de largura
- Formato: Fotos do time completo/elenco

Depois de adicionar as imagens, execute:
```bash
python3 futebol_historico/adicionar_imagens_times.py --forcar
```
